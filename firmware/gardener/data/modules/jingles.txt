# jingles.txt — the named note sequences a routine can find and play.
#
# One jingle per line, four fields separated by |:
#
#   <identifier>|<display name>|<short label>|<note sequence>
#
# The identifier is the stable key stored in settings.ini and passed to the jingles module. The
# display name is what a routine can show; the short label is what fits on the panel. The sequence
# is buzzer.play() notation: note:ms pairs separated by spaces, and r for a rest.
#
# A line starting with # is a comment and a blank line is skipped, so a sharp in a sequence stays a
# note. An entry that is malformed, carries an empty field or holds a sequence the player refuses
# is reported at boot and left out.
